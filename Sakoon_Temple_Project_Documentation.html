3. Global Timezone & Dual-Clock Architecture

Physical sanctum ceremonies at Sakoon Temple occur in accordance with Indian Standard Time (IST, UTC+5:30). However, international devotees participate from different continents. To guarantee absolute clarity, the platform employs a Dual-Clock Architecture:

1. Sanctum Ground-Truth Time (IST)

The authoritative temple sanctum reference clock. Governs gate openings (05:30 AM), midday Vishram (12:30 PM – 04:30 PM), and evening Shayan Aarti (09:15 PM).

2. Devotee Local Country Time

Dynamically calculated based on the devotee's selected nation. Automatically incorporates seasonal 1-hour DST adjustments (e.g., EDT/EST in USA, BST/GMT in UK, AEDT/AEST in Australia).

B. Scientific DST Calculation Algorithm:

// CountryTimezoneService (src/app/services/country-timezone.service.ts)
public isDstActiveInCountry(country: CountryConfig, now: Date = new Date()): boolean {
  if (!country.isDstSupported) return false;
  if (country.dstHemisphere === 'northern') {
    // Northern Hemisphere: 2nd Sunday of March to 1st Sunday of November (+1h)
    const dstStart = this.getNthWeekdayOfMonth(now.getFullYear(), 2, 0, 2);
    const dstEnd = this.getNthWeekdayOfMonth(now.getFullYear(), 10, 0, 1);
    return now >= dstStart && now < dstEnd;
  } else {
    // Southern Hemisphere (Australia): 1st Sunday of October to 1st Sunday of April (+1h)
    const dstStart = this.getNthWeekdayOfMonth(now.getFullYear(), 9, 0, 1);
    const dstEnd = this.getNthWeekdayOfMonth(now.getFullYear(), 3, 0, 1);
    return now >= dstStart || now < dstEnd;
  }
}

4. Autonomous Hindu Panchang & Calendar Engine

The Sakoon Temple Hindu Calendar (/calendar) operates on pure astronomical lunisolar formulas executed entirely client-side. It computes precise Tithis, Nakshatras, Pakshas, Vikram Samvat epochs, and auspicious Muhurats on the fly without any server round-trips.

Dynamic Localized Muhurat Conversion: A universal country selector is embedded directly in the calendar header. When a devotee selects their country (e.g. USA or UK), auspicious Abhijit Muhurat and inauspicious Rahu Kaal time windows automatically re-calculate and display in their local timezone.

Four Core Astronomical Calculation Steps:

1. Julian Day & Planetary Longitudes

Gregorian dates are converted to Julian Day Epoch (J2000):

JD = (time_in_ms / 86400000) + 2440587.5
d = JD - 2451545.0
Sun_Long = (280.460 + 0.9856474 * d) % 360
Moon_Long = (218.316 + 13.176396 * d) % 360
2. Tithi & Lunar Paksha Derivation

Derived from the 12° angular elongation between Sun and Moon:

elongation = (Moon_Long - Sun_Long + 360) % 360
tithiIndex = Math.floor(elongation / 12) + 1
// 1 to 15: Shukla Paksha (Waxing to Purnima)
// 16 to 30: Krishna Paksha (Waning to Amavasya)
3. 27 Nakshatras Computation

The 360° lunar orbit is divided into 27 equal 13.333° spans:

nakshatraIndex = Math.floor(Moon_Long / 13.333333)
// Maps Ashwini (0) through Revati (26)
4. Vikram Samvat & Hindu Months

Synchronized to Chaitra Shukla Pratipada:

vikramSamvat = (month > 2 || (month === 2 && day >= 22)) 
               ? year + 57 : year + 56;
// Chaitra, Vaisakha, Jyeshtha ... Phalguna

Strict Uniform 7-Column Grid Architecture:

  • Identical Cell Geometry (136px): On desktop, all 7 day columns maintain strict uniform height and width, preventing grid collapse or uneven spacing.
  • Horizontal Touch Container on Mobile: To prevent cramped date cards on narrow screens, a smooth touch-enabled horizontal scroll container ensures pristine readability.
  • Multi-Year Astronomical Range: Devotees can browse any month from 2024 through 2032+ with sub-millisecond calculation speeds.
